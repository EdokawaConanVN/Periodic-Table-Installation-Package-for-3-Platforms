# Bảng Tuần Hoàn 118 Nguyên Tố Hóa Học (PWA) - By PhuocDev

Ứng dụng Tra cứu Bảng Tuần Hoàn Nguyên Tố Hóa Học đa nền tảng, hỗ trợ đầy đủ cho **Android**, **Windows (PC)** và **iOS (iPhone/iPad)**.

---

## 📦 HƯỚNG DẪN CÀI ĐẶT DÀNH CHO CÁC NỀN TẢNG

### 📱 1. Dành cho Android
1. Tải file **`BangTuanHoan_Android.apk`** từ phần **Assets** bên dưới.
2. Mở file `.apk` vừa tải về trên điện thoại và chọn **Cài đặt** (Install).
3. Nếu điện thoại hỏi cấp quyền cài đặt từ nguồn không xác định, bấm **Cho phép** (Allow).
4. Mở app ngoài Màn hình chính và sử dụng!

---

### 💻 2. Dành cho Windows (PC / Laptop)

#### Cách 1: Cài qua file đóng gói (Offline)
1. Tải file **`BangTuanHoan_PC.zip`** về máy tính.
2. Giải nén file `.zip`.
3. Tìm file **`install.cmd`** (hoặc `Install-App.ps1`), **nhấp chuột phải** -> Chọn **Run as administrator** (Chạy với quyền quản trị viên).
4. Chờ bảng CMD chạy xong, ứng dụng sẽ tự động xuất hiện trên Desktop và Menu Start.

#### Cách 2: Cài trực tiếp từ trình duyệt (Nhanh nhất)
1. Mở trình duyệt **Microsoft Edge** hoặc **Google Chrome**.
2. Truy cập địa chỉ: `https://yeuhoa.netlify.app/`
3. Nhìn lên góc phải thanh địa chỉ URL, bấm vào biểu tượng **Cài đặt App 🖥️** (Install App).
4. Chọn **Đồng ý / Ghim vào Taskbar** để tạo lối tắt ngoài Desktop.

---

### 🍎 3. Dành cho iPhone / iPad (iOS)

#### Cách 1: Dùng file Cấu hình (Khuyên dùng)
1. Mở trình duyệt **Safari** trên iPhone, tải file **`BangTuanHoan_iOS.mobileconfig`**.
2. Trên màn hình hiện thông báo *Đã tải về hồ sơ* -> Bấm **Đóng**.
3. Vào **Cài đặt (Settings)** trên iPhone -> Chọn mục **Đã tải về hồ sơ** (Profile Downloaded) ở ngay phía trên.
4. Bấm **Cài đặt** ở góc trên bên phải -> Nhập mật khẩu iPhone -> Bấm **Cài đặt** xác nhận.
5. Icon ứng dụng sẽ tự động xuất hiện ngoài Màn hình chính.

#### Cách 2: Thêm trực tiếp từ Safari
1. Mở trình duyệt **Safari** trên iPhone/iPad và truy cập: `https://yeuhoa.netlify.app/`
2. Bấm nút **Chia sẻ** (biểu tượng hình vuông có mũi tên chỉ lên ở thanh công cụ dưới màn hình).
3. Cuộn xuống chọn **Thêm vào MH chính** (*Add to Home Screen*).
4. Bấm **Thêm** ở góc trên bên phải.
